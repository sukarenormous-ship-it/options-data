# แผนทำหนังสือ "Quant for Non-Quant"

> **แก่นเล่ม:** quant ไม่ใช่อินดิเคเตอร์ — quant คือ *ระบบความคิด*
> เอกสารนี้คือพิมพ์เขียวลงมือ: เอา **จุดดี** ของหนังสือทุกเล่มในคลัง (14 เล่ม กระจายอยู่ 19 branch)
> มาใช้, **ปรับจุดอ่อน** ที่รีวิวจริงจับได้ซ้ำ ๆ, และ **เติมส่วนที่ขาด** ที่ยังไม่มีเล่มไหนทำ

- ชื่อชั่วคราว: **คิดแบบ Quant** · *Quant for Non-Quant*
- คำโปรย: *"อินดิเคเตอร์บอกคุณว่าเส้นตัดกัน — quant บอกคุณว่าคุณจะรู้ได้ยังไงว่าตัวเองคิดผิด"*
- ไฟล์: `docs/nq-part0..9.html` + `docs/nq-index.html` + ภาคผนวก `docs/nq-appendix-*.html`
- **หมายเหตุที่ตั้งไฟล์:** ตัวหนังสือต้องไปอยู่ repo `claude-code-project` (`docs/` เดียวกับเล่มอื่น) — session นี้กำหนดให้ push ได้เฉพาะ `options-data` จึงวางเฉพาะ *แผน* ไว้ที่นี่ก่อน (ดู §12)

## 5. แก่นเล่ม — "สายการผลิตความเชื่อ" 8 สถานี

> **metaphor เดียวตลอดเล่ม** (ตามกฎ craft v4): ความเชื่อดิบเข้าปลายสายพานด้านหนึ่ง
> ออกอีกด้านเป็น *ตำแหน่งที่มีขนาด มีกฎออก และมีวิธีรู้ว่าตัวเองผิด*

```
ความรู้สึก ─▶ ① ข้อความ ─▶ ② ฐาน ─▶ ③ การวัด ─▶ ④ การกระจาย
                                          ▲
                              อินดิเคเตอร์อยู่ตรงนี้ — สถานีเดียว
                                          │
             ⑧ บันทึก ◀─ ⑦ ขนาด ◀─ ⑥ โครงสร้าง ◀─ ⑤ ต้นทุน ◀───┘
                  └────────── ป้อนกลับเข้า ① ──────────┘
```

| สถานี | คำถามประจำสถานี | ถ้าข้ามสถานีนี้จะเจ็บแบบไหน |
|---|---|---|
| ① **ข้อความ** | ฉันเชื่ออะไร แบบที่ *ผิดได้* | เถียงกับตัวเองไม่จบ ไม่มีวันรู้ว่าถูกหรือฟลุก |
| ② **ฐาน** | ถ้าไม่ทำอะไรเลย ปกติมันเป็นยังไง | ตื่นเต้นกับสิ่งที่เกิดขึ้นเป็นปกติอยู่แล้ว |
| ③ **การวัด** | วัดด้วยอะไร และมันวัด *ถูกตัว* ไหม | เชื่อเซ็นเซอร์ที่วัดผิดตัว (← ที่อินดิเคเตอร์อยู่) |
| ④ **การกระจาย** | ช่วงและหางเป็นยังไง ไม่ใช่แค่ค่ากลาง | ถูกบ่อยแต่เจ๊งครั้งเดียวจบ |
| ⑤ **ต้นทุน** | ใครอยู่อีกฝั่ง เก็บค่าผ่านทางเท่าไร | edge ตายตรง bid/ask โดยไม่รู้ตัว |
| ⑥ **โครงสร้าง** | ความเชื่อนี้ควรมีหน้าตาการจ่ายผลแบบไหน | ซื้อของถูกทางแต่ผิดรูป |
| ⑦ **ขนาด** | ทนได้แค่ไหน (ไม่ใช่มั่นใจแค่ไหน) | ถูกทางแต่ตายก่อนถึง |
| ⑧ **บันทึก** | จดอะไรไว้ก่อน แล้วอะไรพิสูจน์ว่าผิด | ทำซ้ำความผิดเดิมทั้งชีวิต |

**ประโยคทองของเล่ม (`.pq`):** *อินดิเคเตอร์คือเครื่องมือวัดที่สถานีที่ 3 — คนที่ขาดทุนไม่ได้เลือกเครื่องมือวัดผิด เขาแค่ไม่มีอีก 7 สถานี*

## 9. กฎเหล็ก 10 ข้อ

1. **quant ไม่ใช่อินดิเคเตอร์** — ทุกบทต้องมีกล่อง 🧠 ที่ย้ำเรื่องนี้จากมุมใหม่ ไม่ใช่พูดซ้ำคำเดิม
2. **สัญชาตญาณมาก่อนสูตรเสมอ** — ทั้งเล่มมีสมการได้ไม่เกิน ~15 ตัว และทุกตัวมีย่อหน้าภาษาคนนำ
3. **Write Once, Reference Everywhere** — เล่มนี้ไม่เป็นบ้านของทฤษฎีใดเลย ถ้าเนื้อหาลึกกว่า 🟢 ให้ลิงก์ไปเล่มเดิม
4. **ห้ามเสนอทางเลือกโดยไม่มีค่าเริ่มต้น** (W4)
5. **ตัวเลขทุกตัวมาจาก `nq-figures.json`** — ห้ามพิมพ์ตัวเลขลอย ๆ ในบท (W7)
6. **ห้ามอ้างถึงสิ่งที่ผู้อ่านเปิดดูไม่ได้** — ทุกลิงก์ต้องคลิกได้จริง (W8)
7. **ห้าม hallucinate** paper/เกร็ด/ตัวเลข — ไม่มั่นใจให้ตัด (W12)
8. **โครงสร้าง HTML จริง** — `<ul>/<ol>/<p>` ไม่ใช่ `<br>` ปลอม · `.fm` เก็บเฉพาะสูตร · ห้ามแตะ `<wbr>` script (W11)
9. **ไฟล์เดียวต่อ Part** — ไม่ทำ card/narrative แยกไฟล์ เพราะ dual edition ทำให้เนื้อหาแตกกัน (W14)
10. **ทุก Part ต้องผ่าน Monday-Morning Test ระดับ Part** — จบ Part แล้วผู้อ่าน *ทำอะไรได้เพิ่มขึ้น 1 อย่าง* ที่เขียนออกมาเป็นประโยคได้

## 11. เกณฑ์ "เล่มเสร็จ" — Monday-Morning Test ฉบับ non-quant

> คนที่ **ไม่เคยเรียนสถิติและไม่เขียนโค้ด** อ่านจบแล้ว ภายใน **1 ชั่วโมง** ต้องผลิตของ 6 ชิ้นนี้ได้ด้วยตัวเอง:

1. **ข้อความที่ผิดได้** 1 ข้อ เกี่ยวกับตลาดที่ตัวเองเทรด (ครบ 5 ช่อง)
2. **ฐาน** ของข้อความนั้น — ปกติเกิดบ่อยแค่ไหน และหาตัวเลขนั้นมาจากไหน
3. **วิธีวัด** ที่บอกได้ว่ากำลังวัดอะไรจริง ๆ และมันพลาดตรงไหน
4. **ต้นทุนต่อรอบ** ของตลาดตัวเอง + อัตราชนะขั้นต่ำที่ต้องได้ถึงจะเสมอ
5. **ขนาดไม้** พร้อมเหตุผลที่อ้างอิง *ความทน* และ **กฎหยุด** 1 ข้อ
6. **บรรทัดในสมุด** ที่เขียนไว้ก่อนเข้าไม้ ว่าอะไรจะพิสูจน์ว่าตัวเองผิด

ถ้ามีข้อไหนทำไม่ได้ → Part ที่รับผิดชอบข้อนั้น **ยังไม่ผ่าน**
