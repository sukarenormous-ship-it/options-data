# บทที่ 3 — อ่านภาพ copula ให้เป็น

> **บทนี้ตอบ:** เมื่อ plot (u,v) บนสี่เหลี่ยมจัตุรัสหน่วยแล้ว จะอ่านอะไรออกมาได้บ้าง

---

## 3.1 ทำไมต้องดูภาพก่อน fit

ก่อนจะเลือก family ก่อนจะ optimize อะไรทั้งนั้น — **plot ก่อน**

เหตุผลคือ scatter ของ pseudo-observations เป็นภาพของความสัมพันธ์ที่
**ไม่มี marginal ปนเลย** สิ่งที่คุณเห็นคือโครงสร้างล้วน ๆ และตาคนอ่านภาพนี้
เก่งกว่าที่คิด — คุณจะเห็นความไม่สมมาตรที่ AIC มองไม่เห็น

ขั้นตอน:

```
x, y  →  u = rank(x)/(n+1),  v = rank(y)/(n+1)  →  scatter(u, v)
```

ภาพที่ได้จะอยู่ในกรอบ [0,1]² และ**การกระจายตัวตามขอบแต่ละด้านจะแบนเสมอ**
โดยโครงสร้าง ถ้าไม่แบน แปลว่าโค้ดคุณผิด (sanity check ฟรี ๆ)

---

## 3.2 ภาษาของสี่มุม

จำแค่นี้พอ:

```
        v = 1  (Y อยู่ percentile สูง)
          ┌───────────────┐
          │ ○           ● │   ● มุมขวาบน = ทั้งคู่พุ่งขึ้นพร้อมกัน  → upper tail dependence
          │               │
          │               │
          │ ●           ○ │   ● มุมซ้ายล่าง = ทั้งคู่ร่วงพร้อมกัน   → lower tail dependence
          └───────────────┘
        v = 0            u = 1
```

- **กระจุกที่มุมซ้ายล่างและขวาบน** → dependence เชิงบวก
- **กระจุกเฉพาะซ้ายล่าง** → เจ๊งพร้อมกันแต่ไม่รวยพร้อมกัน (asymmetric)
- **กระจุกที่มุมซ้ายบน/ขวาล่าง** → dependence เชิงลบ
- **กระจายสม่ำเสมอทั้งกรอบ** → เป็นอิสระต่อกัน

ความหนาแน่นที่ **มุม** คือสิ่งที่ correlation มองไม่เห็น
และเป็นสิ่งที่คุณควรมองก่อนเป็นอันดับแรก

---

## 3.3 นิยามที่ตรงกับภาพ: tail dependence

**Upper tail dependence**

```
λ_U = lim   P( V > q | U > q )
     q→1⁻
```

อ่านว่า: "ถ้ารู้ว่า X อยู่เหนือ percentile ที่ q แล้ว Y จะอยู่เหนือด้วย
ด้วยความน่าจะเป็นเท่าไร เมื่อ q วิ่งไปสุดขั้ว"

**Lower tail dependence**

```
λ_L = lim   P( V ≤ q | U ≤ q )
     q→0⁺
```

ค่าอยู่ใน [0,1]:
- `λ = 0` → **asymptotic independence** ยิ่งสุดขั้ว ยิ่งไม่เกี่ยวกัน
- `λ > 0` → **asymptotic dependence** ต่อให้สุดขั้วแค่ไหน ก็ยังมีโอกาสเจอพร้อมกัน

**นี่คือตัวเลขที่ Gaussian บังคับให้เป็น 0 เสมอ ไม่ว่า ρ จะเท่าไร
(ตราบใดที่ ρ < 1)** ซึ่งเป็นเหตุผลหลักที่คนในวงการ risk เลิกใช้
Gaussian copula กันหลังปี 2008 (บทที่ 4 หัวข้อ 4.2 จะให้ความเป็นธรรม
กับมันอีกด้านหนึ่ง)

ประมาณจากข้อมูลได้แบบหยาบ ๆ ด้วย:

```
λ̂_L(q) = #{ uᵢ ≤ q และ vᵢ ≤ q } / #{ uᵢ ≤ q }
```

แล้ว plot `λ̂_L(q)` เทียบกับ q ที่ q เล็กลงเรื่อย ๆ ถ้ามันลู่เข้าหาเลขที่ไม่ใช่ 0
นั่นคือหลักฐานของ tail dependence — แต่ระวัง: ที่ q เล็กมาก ๆ ตัวส่วนจะเหลือ
ไม่กี่จุด ค่าที่ได้จะเต้นแรงมาก อย่าอ่านจุดสุดท้ายเป็นคำตอบ

---

## 3.4 ลายนิ้วมือของแต่ละตระกูล

ฝึกจำภาพเหล่านี้ แล้วคุณจะเดา family ได้ก่อน fit

**Gaussian** — วงรี สมมาตรทั้งสี่ทิศ มุมทั้งสี่บางลงเรื่อย ๆ
```
λ_U = λ_L = 0   (เสมอ)
```
เหมาะเมื่อ: ความสัมพันธ์เป็นเรื่องของ "ระดับกลาง" ไม่ใช่เรื่องของ tail

**Student-t** — เหมือน Gaussian แต่**มีก้อนหนาที่มุมซ้ายล่างและขวาบนพร้อมกัน**
```
λ_U = λ_L > 0   ขึ้นกับ ν (ν เล็ก → tail หนา)
```
เหมาะเมื่อ: ต้องการ tail dependence แบบสมมาตร เป็นค่า default ที่ปลอดภัยที่สุด
สำหรับ risk work

**Clayton** — กระจุกแน่นที่**มุมซ้ายล่างอย่างเดียว** ขวาบนบางเหมือนอิสระ
```
λ_L = 2^(−1/θ) > 0,   λ_U = 0
```
เหมาะเมื่อ: "ร่วงพร้อมกัน แต่ขึ้นแยกกัน" — ซึ่งเป็นเรื่องที่พบบ่อยใน equity
และใน crypto altcoin

**Gumbel** — กลับด้านของ Clayton กระจุกที่**มุมขวาบน**
```
λ_U = 2 − 2^(1/θ) > 0,   λ_L = 0
```
เหมาะเมื่อ: "พุ่งพร้อมกัน" เช่นช่วง mania ของ altcoin หรือ implied vol
ที่พุ่งพร้อมกันทั้งกระดาน

**Frank** — สมมาตร แต่**ไม่มี tail dependence เลย** ความสัมพันธ์เข้มที่กลาง ๆ
```
λ_U = λ_L = 0
```
เหมาะเมื่อ: อยากได้ dependence ที่แรงพอควรแต่ไม่อยากสมมติ tail
รองรับ dependence เชิงลบได้ด้วย (ต่างจาก Clayton/Gumbel มาตรฐาน)

## 3.5 กับดักการอ่านภาพ

**กับดัก 1 — ตาเห็น pattern ในความสุ่ม**
ที่ n = 200 มุมล่างซ้ายจะมี "ก้อน" ที่ดูน่าเชื่อโผล่มาเองได้ง่ายมาก
ก่อนตีความ ให้ plot ข้อมูลจำลองจาก independence copula ที่ n เท่ากันดูสัก 5 ภาพ
คุณจะตกใจว่ามันดูมีโครงสร้างแค่ไหน

**กับดัก 2 — จุดทับกัน**
ที่ n มาก จุดทับกันจนอ่านความหนาแน่นไม่ออก ใช้ `alpha=0.2`,
hexbin หรือ 2D histogram แทน

**กับดัก 3 — ลืมว่านี่คือ in-sample**
ภาพที่เห็นคือหน้าต่างที่คุณเลือก เลื่อนหน้าต่างไป 3 เดือนแล้ว plot ใหม่
ถ้าภาพเปลี่ยนหน้ามือเป็นหลังมือ นั่นคือข้อมูลที่สำคัญกว่าภาพแรก
(บทที่ 6)

**กับดัก 4 — vol clustering ปลอมตัวเป็น tail dependence**
พูดไปแล้วในบทที่ 2 แต่ย้ำเพราะมันคือสาเหตุอันดับหนึ่งของ
"Clayton θ สูงลิ่ว" ที่เชื่อไม่ได้ ถ้าเห็นก้อนหนาที่มุมซ้ายล่าง
คำถามแรกคือ "กรอง vol clustering แล้วยัง"
(บทที่ 2 มีทางลัดสองบรรทัดให้ ไม่ต้องรู้จัก GARCH ก็ทำได้)

## 3.6 เครื่องมือดูภาพอื่นที่คุ้มค่า

**Chi-plot และ K-plot** (Genest & Favre, 2007) — กราฟวินิจฉัยที่ออกแบบมา
ให้ "ความเป็นอิสระ" มีหน้าตาที่คาดเดาได้ ทำให้เห็นการเบี่ยงเบนง่ายกว่า scatter ธรรมดา

**Conditional scatter** — แบ่งข้อมูลตาม regime (vol สูง/ต่ำ, ก่อน/หลังเหตุการณ์)
แล้ว plot แยก ถ้าโครงสร้างต่างกันชัด อย่าใช้ copula ตัวเดียวคลุมทั้งช่วง

**λ̂(q) curve** — ตามหัวข้อ 3.3 นี่คือกราฟที่ผมคิดว่าคุ้มค่าที่สุดต่อบรรทัดโค้ด
เพราะมันตอบคำถามที่สำคัญที่สุดโดยตรง: tail dependence มีจริงไหม

---

## 3.7 สิ่งที่ควรจำจากบทนี้

**สามบรรทัดสรุป**

1. scatter ของ (u,v) คือภาพของความสัมพันธ์ที่ไม่มี marginal ปน — ดูก่อน fit เสมอ
2. ความหนาแน่นที่ **มุม** คือข้อมูลที่ correlation มองไม่เห็น และมักสำคัญที่สุด
3. ก่อนเชื่อ pattern ที่เห็น ให้ plot ข้อมูลสุ่มที่ n เท่ากันเทียบเสมอ
