# Copula สำหรับ Statistical Arbitrage
### หนังสืออ่านสำหรับคนที่จะเอาไปใช้จริง ไม่ใช่แค่รู้จัก

---

## หนังสือเล่มนี้เถียงอะไร

หนังสือ copula ส่วนใหญ่จบลงที่ "ดูสิ เราจับ tail dependence ได้" แล้วปล่อยให้คนอ่านคิดเอง
ว่าจะเอาไปทำเงินยังไง เล่มนี้เดินอีกทาง — เริ่มจากคำถามว่า *ระบบเทรดจริงต้องการอะไร*
แล้วค่อยถามว่า copula ตอบส่วนไหนได้

ข้อสรุปที่หนังสือทั้งเล่มพาไปหา คือประโยคเดียวนี้:

> **Copula ไม่ได้บอกว่าอะไรจะกลับมา แต่บอกว่าสถานะของสินทรัพย์หนึ่ง "แปลกแค่ไหน"
> เมื่อรู้ว่าสินทรัพย์อื่นกำลังอยู่ในสถานะอะไร**

หรือถ้าจะใช้ภาพ: **copula บอกว่าเชือกถูกผูกอย่างไร ไม่ได้บอกว่าเชือกมีแรงดึงกลับ**

ความแตกต่างสองอย่างนั้นคือเส้นแบ่งระหว่างงานวิจัยที่ backtest สวยกับพอร์ตที่รอดจริง
และคือเหตุผลที่บทที่ 9 ทั้งบทถูกเขียนขึ้นเพื่อเรื่องนี้เรื่องเดียว

## วิธีอ่าน

**ถ้ามีเวลา 20 นาที** — อ่านบท 1 → บท 9 → บท 11
สามบทนี้คือข้อโต้แย้งของหนังสือทั้งเล่ม แต่มันยืมศัพท์จากบทที่ข้ามไปสี่ตัว
จำเท่านี้ก่อนพอ:

```
h(u|v)  ความน่าจะเป็นที่ A จะต่ำกว่า percentile u เมื่อรู้ว่า B อยู่ percentile v
        ถ้าสองตัวไม่เกี่ยวกันเลย h(u|v) = u  → ระยะห่างจาก u คือข้อมูลที่ได้เพิ่ม
MI      = h(u|v) − 0.5   สัญญาณเทรดที่สร้างจาก h  (บทที่ 8)
λ_L     ความน่าจะเป็นที่จะร่วงหนักพร้อมกันตอนสุดขั้ว  (บทที่ 3)
breadth จำนวนเดิมพันที่อิสระจริง ซึ่งน้อยกว่าจำนวนสถานะที่ถือเสมอ  (บทที่ 10)
```

**ถ้าจะ implement** — อ่านเรียงบท 2 → 4 → 5 → 7 → 8 แล้วเปิดภาคผนวก B ควบคู่
(บท 4 ข้ามไม่ได้ เพราะบท 5 ใช้สูตร τ→θ ของแต่ละตระกูลตลอด และบท 7 คือบทที่
บอกว่าจะเอา residual มาจากไหน ซึ่งทุกบทหลังจากนั้นสมมติว่าคุณมีแล้ว)

**ถ้ามีระบบอยู่แล้วและอยากรู้ว่า copula คุ้มไหม** — อ่านบท 9 หัวข้อ 9.5–9.6
(การทดสอบสองอันที่ใช้เวลาเขียนสิบนาที) แล้วข้ามไปบท 12 ทั้งบท
บทนั้นคือแบบการทดลองที่จะให้คำตอบว่า "คุ้ม" หรือ "แค่พูดซ้ำเรื่องเดิม
ในรูปที่ซับซ้อนกว่า"

## ต้องรู้อะไรมาก่อน

- ความน่าจะเป็นระดับพื้นฐาน: CDF, PDF, conditional probability
- สถิติพื้นฐาน: quantile, correlation, maximum likelihood พอเข้าใจว่าคืออะไร
- Python + numpy/scipy ถ้าจะรันโค้ดในภาคผนวก B

**ไม่ต้อง**รู้ measure theory หนังสือเล่มนี้เขียนสำหรับคนที่จะเอาไปสร้างระบบ
ไม่ใช่คนที่จะไปพิสูจน์ทฤษฎีบท ที่ไหนที่ต้องเลือกระหว่างความเข้มงวดกับความเข้าใจ
เล่มนี้เลือกความเข้าใจ แล้วชี้ไปที่งานต้นฉบับในภาคผนวก C แทน

## เรื่องสัญลักษณ์

หนังสือเล่มนี้เขียนสูตรเป็นข้อความธรรมดา ไม่ใช้ LaTeX เพื่อให้อ่านได้ทุกที่
ทั้งบน GitHub, ในเทอร์มินัล, หรือบนหน้าเว็บ ตัวอย่าง:

```
C(u,v)  = copula
h(u|v)  = ∂C(u,v)/∂v = P(U ≤ u | V = v)
λ_U     = tail dependence ด้านบน
τ       = Kendall's tau
```

รายการเต็มอยู่ใน [ภาคผนวก A](appendix-a-formulas.md)
