# บทที่ 4 — ตระกูลของ copula

> **บทนี้ตอบ:** มี copula ให้เลือกกี่แบบ ต่างกันตรงไหน และเลือกอย่างไรโดยไม่หลอกตัวเอง

---

## 4.1 แผนที่ก่อนลงรายละเอียด

copula ที่ใช้จริงในงานการเงินแบ่งเป็นสองกลุ่มใหญ่

**Elliptical** — ได้จากการเอา elliptical distribution มาถอด marginal ออก
ขยายไปหลายมิติได้ง่ายผ่าน correlation matrix

**Archimedean** — สร้างจากฟังก์ชัน generator ตัวเดียว มีพารามิเตอร์น้อย
ควบคุม tail ได้แม่น แต่ขยายไปหลายมิติได้ลำบาก

```
                    copula
                   /      \
           Elliptical    Archimedean
            /     \       /   |   \
      Gaussian   t   Clayton Gumbel Frank ...
       λ=0     λ>0    λ_L>0  λ_U>0   λ=0
```

**เกณฑ์เลือกที่ควรใช้เป็นหลัก ไม่ใช่ AIC แต่คือ tail ที่คุณเชื่อว่ามีจริง**
เพราะ tail คือสิ่งที่มีผลกับ P&L มากที่สุดและเป็นสิ่งที่ข้อมูลบอกเราน้อยที่สุด
(ตามนิยาม เหตุการณ์ tail มีน้อย)

---

## 4.2 Gaussian copula

```
C(u,v; ρ) = Φ_ρ( Φ⁻¹(u), Φ⁻¹(v) )
```

โดย `Φ_ρ` คือ bivariate normal CDF และ `Φ⁻¹` คือ inverse normal CDF

| คุณสมบัติ | ค่า |
|---|---|
| พารามิเตอร์ | ρ ∈ (−1, 1) |
| λ_L, λ_U | **0 ทั้งคู่** (เมื่อ ρ < 1) |
| ความสัมพันธ์กับ τ | τ = (2/π) · arcsin(ρ) |
| ความสัมพันธ์กับ ρ_S | ρ_S = (6/π) · arcsin(ρ/2) |
| หลายมิติ | ง่าย — ใช้ correlation matrix |

**ข้อดี:** เร็ว เสถียร ขยายมิติง่าย ทุกคนเข้าใจ
**ข้อเสีย:** บังคับว่าไม่มี tail dependence

Gaussian copula เป็นตัวร้ายในเรื่องเล่าเรื่องวิกฤต 2008 (ผ่านการใช้กับ CDO)
แต่ให้เป็นธรรม: ปัญหาไม่ใช่ตัวโมเดล ปัญหาคือคนใช้มันในที่ที่ tail dependence
เป็นเรื่องสำคัญที่สุด ทั้งที่โมเดลบอกตั้งแต่ต้นแล้วว่ามันตั้งค่านั้นเป็นศูนย์

**ยังใช้ได้ดีเมื่อ:** เป็น baseline สำหรับเปรียบเทียบ, งานที่สนใจความสัมพันธ์
ระดับกลาง, หรือเมื่อมิติเยอะจนตัวอื่นไม่ไหว

---

## 4.3 Student-t copula

```
C(u,v; ρ,ν) = t_{ρ,ν}( t_ν⁻¹(u), t_ν⁻¹(v) )
```

| คุณสมบัติ | ค่า |
|---|---|
| พารามิเตอร์ | ρ ∈ (−1,1), ν > 2 (degrees of freedom) |
| λ_U = λ_L | 2 · t_{ν+1}( −√(ν+1) · √((1−ρ)/(1+ρ)) ) |
| หลายมิติ | ง่าย — correlation matrix + ν ตัวเดียว |

ตัวอย่างค่า λ:

| ρ | ν=4 | ν=8 | ν=30 |
|---|---|---|---|
| 0.5 | 0.25 | 0.12 | 0.00 |
| 0.8 | 0.49 | 0.34 | 0.07 |

สังเกตว่า **ν คือปุ่มควบคุม tail โดยตรง** และเมื่อ ν → ∞ มันกลายเป็น Gaussian
ดังนั้น Gaussian คือ special case ของ t — ซึ่งแปลว่า **ถ้าลังเล ให้ใช้ t
แล้วปล่อยให้ข้อมูลตัดสิน ν** ถ้าข้อมูลบอกว่า Gaussian พอ มันจะ fit ν สูงมาเอง

นี่คือ default ที่ผมแนะนำสำหรับงาน risk ในคริปโต: สมมาตร, มี tail,
ขยายมิติได้, และมี Gaussian เป็นกรณีพิเศษให้ถอยกลับได้

**ข้อจำกัด:** บังคับให้ λ_U = λ_L ซึ่งขัดกับที่เห็นในตลาดจริงที่มัก
"ร่วงพร้อมกันมากกว่าขึ้นพร้อมกัน"

---

## 4.4 Archimedean copula

ทุกตัวในตระกูลนี้สร้างจาก generator `φ`:

```
C(u,v) = φ⁻¹( φ(u) + φ(v) )
```

โดย `φ: [0,1] → [0,∞]` ลดลง นูน และ `φ(1) = 0`
เปลี่ยน φ ก็ได้ copula คนละตัว

### Clayton — สำหรับ "ร่วงพร้อมกัน"

```
C(u,v; θ) = ( u^(−θ) + v^(−θ) − 1 )^(−1/θ),    θ > 0
```

| | |
|---|---|
| generator | φ(t) = (t^(−θ) − 1)/θ |
| λ_L | 2^(−1/θ) |
| λ_U | 0 |
| τ | θ / (θ + 2) |

θ → 0 คือเป็นอิสระ, θ → ∞ คือเหมือนกันสมบูรณ์

**ใช้เมื่อ:** ภาพ scatter หนาที่มุมซ้ายล่างชัดกว่าขวาบน
ซึ่งพบบ่อยใน altcoin เทียบกับ BTC

### Gumbel — สำหรับ "พุ่งพร้อมกัน"

```
C(u,v; θ) = exp( −[ (−ln u)^θ + (−ln v)^θ ]^(1/θ) ),    θ ≥ 1
```

| | |
|---|---|
| λ_U | 2 − 2^(1/θ) |
| λ_L | 0 |
| τ | 1 − 1/θ |

**ใช้เมื่อ:** สนใจการพุ่งขึ้นพร้อมกัน หรือใช้กับ implied vol / spread
ที่พุ่งพร้อมกันตอน stress

### Frank — dependence โดยไม่มี tail

```
C(u,v; θ) = −(1/θ) · ln( 1 + (e^(−θu) − 1)(e^(−θv) − 1) / (e^(−θ) − 1) )
```

| | |
|---|---|
| θ | ∈ ℝ \ {0} — **รองรับค่าลบ** |
| λ_U, λ_L | 0 ทั้งคู่ |
| τ | 1 − 4/θ + 4·D₁(θ)/θ  (D₁ = Debye function อันดับ 1) |

**ใช้เมื่อ:** อยากได้ dependence ที่แรงตรงกลางแต่ไม่อยากสมมติ tail
หรือต้องการ dependence เชิงลบ

### Joe — upper tail แรงกว่า Gumbel

```
C(u,v; θ) = 1 − [ (1−u)^θ + (1−v)^θ − (1−u)^θ(1−v)^θ ]^(1/θ),   θ ≥ 1
λ_U = 2 − 2^(1/θ)
```

ใช้เมื่อ upper tail แรงมากจน Gumbel ไม่พอ

---

## 4.5 สองเทคนิคที่ควรรู้

### Rotation — ยืดหยุ่นฟรี

Clayton จับ lower tail ถ้าอยากได้ upper tail แทน ไม่ต้องเปลี่ยน family
แค่หมุน 180°:

```
C_180(u,v) = u + v − 1 + C(1−u, 1−v)      "survival Clayton"
```

หมุน 90° หรือ 270° ได้ dependence เชิงลบ:

```
C_90(u,v)  = v − C(1−u, v)
C_270(u,v) = u − C(u, 1−v)
```

เท่ากับได้ 4 ทางเลือกจากทุก family ที่ไม่สมมาตร

### Mixture — ผสมเพื่อได้ tail สองด้านที่ไม่เท่ากัน

```
C_mix(u,v) = w · C_Clayton(u,v; θ₁) + (1−w) · C_Gumbel(u,v; θ₂)
```

ได้ `λ_L` และ `λ_U` ที่ต่างกันได้อย่างอิสระ ซึ่งตรงกับตลาดจริงมากกว่า

**แต่:** เพิ่มจาก 1 เป็น 3 พารามิเตอร์ ต้องถามทุกครั้งว่าคุ้มหรือไม่
(บทที่ 13)

---

## 4.6 ตารางเลือกใช้

| คุณเชื่อว่า... | ใช้ | λ_L | λ_U |
|---|---|---|---|
| ไม่มี tail dependence | Gaussian หรือ Frank | 0 | 0 |
| มี tail สองด้านเท่ากัน | **Student-t** | >0 | =λ_L |
| ร่วงพร้อมกันเท่านั้น | Clayton | >0 | 0 |
| พุ่งพร้อมกันเท่านั้น | Gumbel / Joe | 0 | >0 |
| tail สองด้านไม่เท่ากัน | mixture / rotated pair | >0 | >0 ต่างกัน |
| dependence เชิงลบ | Frank หรือ rotated 90°/270° | | |
| มิติเยอะ (d > 5) | Gaussian / t / vine (บทที่ 9) | | |

---

## 4.7 คำเตือนที่สำคัญที่สุดของบทนี้

การเลือก family คือ **degree of freedom ที่คุณเพิ่มให้ตัวเอง**

ถ้าคุณลอง 8 family × 3 rotation × 4 ความยาวหน้าต่าง = 96 ทางเลือก
แล้วเลือกอันที่ backtest ดีที่สุด คุณไม่ได้เลือกโมเดล — **คุณกำลัง fit
noise ด้วยมือ** และ AIC จะไม่ช่วยคุณเลย เพราะ AIC ลงโทษจำนวนพารามิเตอร์
ในโมเดลหนึ่ง ๆ ไม่ได้ลงโทษจำนวนโมเดลที่คุณลอง

ทางแก้ที่ใช้ได้จริงมีสามอย่าง:

1. **เลือก family จากเหตุผลเชิงโครงสร้าง ก่อนดูผลตอบแทน** — ดูภาพ (บทที่ 3)
   ตัดสินใจว่าเชื่อ tail แบบไหน แล้วล็อกไว้
2. **ตรึงไว้ตัวเดียวตลอด out-of-sample** — ถ้าจะเลือกใหม่ ต้องเลือกด้วยข้อมูล
   ในอดีตเท่านั้น ณ เวลานั้น (walk-forward selection) ไม่ใช่เลือกทีเดียวจากทั้งชุด
3. **รายงานผลของทุก family ที่ลอง** ไม่ใช่แค่ตัวที่ชนะ ถ้าผลกระจายกว้างมาก
   แปลว่าคำตอบของคุณคือฟังก์ชันของการเลือก ไม่ใช่ของตลาด

---

## 4.8 สิ่งที่ควรจำจากบทนี้

**สามบรรทัดสรุป**

1. เลือก family จาก **tail ที่คุณเชื่อว่ามีจริง** ไม่ใช่จาก AIC ที่ดีที่สุด
2. Student-t เป็น default ที่ปลอดภัยที่สุด เพราะมี tail และมี Gaussian เป็นกรณีพิเศษ
3. จำนวนทางเลือก family × rotation × window คือช่องทาง overfit ที่ใหญ่ที่สุดของงาน copula

## แบบฝึกหัด

**4.1** สำหรับ τ = 0.5 คำนวณพารามิเตอร์ของ Clayton, Gumbel และ Gaussian
แล้วหา λ_L, λ_U ของแต่ละตัว ทั้งสามมี τ เท่ากันแต่พฤติกรรม tail ต่างกันแค่ไหน

**4.2** สุ่มข้อมูล 2000 จุดจาก Clayton (θ=2) แล้ว fit ด้วย Gumbel
ดูภาพ scatter ของทั้งสอง แล้วดูว่า AIC ลงโทษการเลือกผิดมากพอไหม

**4.3** เขียนฟังก์ชัน `rotate(copula, degrees)` แล้วยืนยันว่า survival Clayton
ให้ λ_U ตรงกับ λ_L ของ Clayton เดิม

**4.4** fit ทั้ง 5 family กับคู่ (ETH, SOL) จากข้อมูลจริง เรียงตาม AIC
ช่องว่างระหว่างอันดับ 1 กับ 3 ห่างกันแค่ไหน มากพอจะมั่นใจหรือไม่
